# Spotify iPod Sync Tool

A desktop application to download Spotify playlists, albums, and tracks, convert them to MP3, and sync to iPod Nano 7G.

## Features
- Download Spotify content via URL
- Sync to iPod Nano 7G with optional media player integration
- Live log and progress tracking

## Usage
1. Enter a Spotify URL in the entry box
2. Click "Download URL" or "Download Liked Songs"
3. Configure your sync tool path (optional)
4. Click "Sync to iPod Nano 7G" to export and sync

## Requirements
- Python 3.x
- CustomTkinter
- zotify_runner.py

## Configuration
- Sync tool path is saved in config.json
- Music library stored in F:\\spotify-ipod\\music_library
